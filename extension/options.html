Tracelet规则与本地数据

站点规则

内置规则为待验证模板。保存后回到聊天页面，点击扩展预览，再授权开启。自定义站点以域名独立分类。

仅匹配用户消息；不要选择整个对话。默认按域名与路径区分会话，使用查询参数的网站请填写参数名。无稳定消息 ID 时按文本和出现次数去重，虚拟列表或编辑消息可能无法可靠关联。

本地数据

扩展副本存放在浏览器本地存储，未单独加密。清空前请先暂停已启用站点，否则页面会再次采集。导出文件可在 Tracelet 中导入。

桌面配对

将此 ID 填入 Mac 应用「连接与设置 → 浏览器扩展」。

仅处理当前页面已加载的消息；不自动翻页，不采集输入框草稿、密码、Cookie 或助手回答。规则错误可能误选内容，启用前务必预览。Safari 暂不支持。
