PRIVACY, IN PLAIN WORDS · 0.2.0

你的记忆，由你掌握。

这份说明对应 Tracelet 0.2.0 测试版，说明应用实际读取、保存和发送什么。

1. 读取哪些内容

采集默认关闭。你开启后，应用监听本机 Codex sessions 和 Claude Code projects 目录下的 JSONL 文件，解析用户消息的文本。解析会临时读取对话文件（其中可能包含助手消息），但只有用户提问及来源元数据会存入数据库。导入功能读取你在文件选择器中选定的 JSON 或 JSONL。我们不监听键盘、不录屏、不读取浏览器 Cookie。

2. 数据放在哪里

对话、时间、平台、会话标识和来源路径，以及候选和已确认记忆，保存在 macOS 的 ~/Library/Application Support/Tracelet/ 中。SQLite 数据库本身未加密；文件权限仅限当前系统用户。建议开启 FileVault，避免共享系统账户。备份软件也可能复制这些文件。没有 Tracelet 云端账号或遥测服务。

3. AI 分析会发送什么

分析需要你选择对话并确认预览。应用仅通过 HTTPS 将预览中显示的提问正文、证据 ID、会话标识、时间及预览中的参考记忆，以及系统分析指令、模型参数发送至 OpenRouter。不会把本地文件路径、API Key 放在分析正文中；API Key 仅用于 Authorization 认证。OpenRouter 再将内容路由到你选择的模型提供商；这些内容适用相应服务商的数据政策，不能视为完全离线。请勿发送你无权分享的内容；原文可能包含个人信息或秘密，发送前务必检查。

应用没有自动后台分析或无提示的模型回退。获取可用模型列表也会连接 OpenRouter。费用由你的 OpenRouter 账户承担。参见 OpenRouter 隐私政策。

4. API Key 如何保护

应用通过 Electron safeStorage 使用 macOS Keychain 保护加密密钥，将 API Key 的加密数据保存到用户数据目录。系统安全存储不可用时拒绝保存。Key 不放在网页、GitHub、安装包、对话数据库或 JSON 导出中。你可以在设置中移除 Key。在聊天或公开文件中暴露的 Key 应立即撤销。

5. 记忆如何确认

AI 输出只作为候选，可能不准确。候选必须引用有效提问证据，通过结构校验后保存；仍需你人工确认或忽略。模型输出的“自评置信度”并非统计准确率。分析不运行工具、不执行提问中的命令，不会自动删除或覆盖你已确认的记忆。

6. 导出、删除与卸载

你可以导出包含原文的 JSON，请妥善保管。清空数据会删除本机提问和记忆并暂停自动采集；不会删除平台的原始对话文件、其他位置的导出或备份，也无法撤回已经发送给模型服务商的请求。重新开启采集会重新导入本地来源。API Key 独立移除。卸载应用不会自动删除用户数据目录。

7. 官网

官网是 GitHub Pages 静态页面，没有登录、表单或分析脚本。页面从同源读取发布状态文件。浏览网站与下载安装包会向 GitHub 基础设施发起网络请求，适用 GitHub 的相关政策。

反馈与联系

可在 GitHub Issues 反馈；请勿在公开 Issue 中粘贴 API Key 或私人对话。
