A FEW THINGS TO KNOW

开始之前，你可能想知道。

哪些平台可以自动采集？＋

首版自动监听 Codex 的 ~/.codex/sessions（支持 CODEX_HOME）和 Claude Code 的 ~/.claude/projects。ChatGPT、Claude 网页版支持导出 JSON 导入；Grok 支持 messages 数组的 JSON 文件导入。不同 Grok 导出格式可能需要适配，详见仓库文档。首版不读取网页、键盘或屏幕。

是否需要订阅？AI 分析如何计费？＋

当前版本开源，应用本身不收取订阅费。你需要自己的 OpenRouter API Key，分析费用由 OpenRouter 按实际调用计费。应用可输入模型 ID，并查询 DeepSeek 实时模型列表。DeepSeek V4 Flash 的可用性须以 OpenRouter 账户实际返回为准。

AI 会自动把猜测当成我的个人信息吗？＋

不会自动接受。分析 Agent 只生成候选记忆，并附带提问证据。模型可能误判，因此每条候选都需要你确认。身份类记忆只应基于你的明确表述，关于某个主题的提问不等于你的身份。

安装包是否经过 Apple 公证？＋

这是早期测试版本。自动发布流程会标明是否已签名和公证；未配置 Apple Developer 证书时生成的是未公证测试包。请先查看 GitHub Release 说明与 SHA-256 校验值。若 macOS 拦截，可按 Apple 官方指引在“系统设置 → 隐私与安全性”中允许；不要全局关闭 Gatekeeper。

现在可以让其他 AI 自动使用这些记忆吗？＋

首版支持采集、分析、审核以及 JSON 导出，尚未提供 MCP 服务或跨平台自动注入。未来可在你授权的范围内，将已确认记忆提供给其他 Agent。
