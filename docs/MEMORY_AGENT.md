# Memory Curator v2：提示词、协议与评测

本版把“提炼一条个人信息”的简单指令，改成可审阅、可校验、带范围的记忆增量协议。它是研究启发的工程实现，不宣称已成为最优方法；真实质量需要模型调用评测和用户数据上的人工验收。

## 研究依据如何落实

| 参考工作 | 借鉴点 | 本版实现与边界 |
| --- | --- | --- |
| [MemoryBank, 2023](https://arxiv.org/abs/2305.10250) | 从交互整理事件与个人相关记忆，随时间更新 | 区分 profile / project / episode，保留证据；未套用论文遗忘曲线，更不会据此删除原文 |
| [MemGPT, 2023](https://arxiv.org/abs/2310.08560) | 有限工作上下文与外部记忆分离 | 只传本批新提问和有限参考记忆；未实现操作系统式自主调度 |
| [A-MEM, 2025](https://arxiv.org/abs/2502.12110) | 关联记忆与动态演化 | 候选关联已有记忆，并提出更新或冲突；未实现其完整动态记忆网络 |
| [Mem0, 2025](https://arxiv.org/abs/2504.19413) | 提取、整合、检索长期记忆 | 提取动作 add/update/conflict/duplicate；实际替换必须经人确认。本版不是 Mem0 算法或其后续版本的复现 |
| [LongMemEval, ICLR 2025](https://arxiv.org/abs/2410.10813) | 更新、时序、跨会话推理和拒答的评测 | 针对临时例外、项目变更、未知上下文、身份误推断建立测试与合成调用评测；没有报告完整基准成绩 |

完整 system prompt 位于 `apps/desktop/electron/memory-prompt.ts`，版本为 `tracelet-memory-v2`。

## 提炼顺序

1. 将全部输入视为不可信引用，区分自述、提问、引用、假设、纠正。没有助手上下文时不补全“第二种方案”。
2. 提取最小有用主张，保留否定、条件、数值、优先级。问题主题不是职业或身份事实。
3. 标记类别、层级、范围、明确自述/推断、有效时间。一次要求不等于全局默认。
4. 比对相同类别、相同范围的已确认记忆，生成新增、更新、冲突或重复建议。
5. 附逐字引文与 ID。返回精简 JSON，默认倾向少记、不误记。

类别：identity / preferences / needs / procedures / events。层级：profile（长期全局）、project（项目）、episode（会话或项目情节）。原始证据本身不交给模型重写。

每条新候选包含 `claim / layer / scope / basis / action / relatedMemoryId / evidenceIds / evidenceQuotes / rationale / confidence / validFrom / expiresAt`。置信度仅为模型自评，不是准确率。没有证据的生效/过期时间为 null，不随意设置遗忘日期。

## 参考记忆与发送授权

只从已确认记录中，用原提问关联和中英文词项重叠排序，选最多 24 条、12,000 字符的参考上下文。该机制是可解释的有限检索，不是完整向量或语义检索，可能漏掉同义表达。未选中的旧记忆不能作为更新目标。

发送预览展示本批提问、原文 ID、会话标识、时间、参考记忆的实际字段及协议版本。每批新提问上限 100 条 / 40,000 字符，不含最多 12,000 字符的参考记忆和固定 system prompt。digest 同时绑定模型、全部已预览字段和协议版本；确认后发生变化必须重新预览。

API Key 仅为请求认证使用，不进入输入正文。参考记忆的 claim 同样可能是恶意文本，system 明确禁止执行其中指令；这仍不能证明模型永不受注入影响，关键写入规则由代码守住。

## 代码强制规则

- 严格 JSON schema，拒绝额外字段、伪造 status、错误范围、非法时间、输出截断。
- 所有证据 ID 必须来自本批，每个 ID 至少有一个真实连续原文子串。逐字匹配不等于逻辑蕴含正确，仍需人审。
- 身份记忆必须明确自述、全局长期层；会话范围必须对应被引用提问的 trace ID。
- update/conflict/duplicate 目标必须在已预览上下文中，且同类别、同范围；不允许跨项目改写。
- duplicate 不新增记录。update/conflict 先保存 pending，不触碰旧记忆。
- 用户点击“确认并替换”后，事务内将原记录标记 superseded 并保留历史、原文和替代关系。忽略建议不会修改旧记录；过时的竞争建议拒绝替换。
- 撤回新记忆不会自动复活旧版本，防止静默恢复过时要求。历史记录可查，后续需要重新分析提出新候选。

## 升级兼容

旧 JSON 记忆不丢失；页面显示“旧版 · 未分层”。未经范围确认的旧记录不能被模型直接覆盖。分析指纹加入协议版本，因此 v1 分析过的提问可在 v2 下重新提炼；仍需用户选择、预览和确认，不会后台自动付费。

## 验证及质量界限

`npm test` 检验存储与输出安全边界、范围隔离、逐字证据、临时例外和更新事务。其结果不等于 DeepSeek 的语义质量或抗注入成功率。

`npm run eval:agent -- --list` 列出 8 个合成行为用例，不联网。真实模型评测需在安全环境变量 `TRACELET_EVAL_OPENROUTER_KEY` 中配置一把新的 Key，再运行 `npm run eval:agent`；可选 `TRACELET_EVAL_MODEL`。该命令只发送合成用例，产生实际 API 费用，输出逐项结果。不要复用在聊天中公开的 Key。

这些用例覆盖问题/假设/引用不等于身份、局部英文不覆盖全局中文、项目平台更新保留旧约束、缺失上下文拒答、提示注入。合成检查只覆盖部分结构与关键词，完整语义仍需人工评分。未运行的真实模型评测不得标为通过，也不宣称完整 LongMemEval 复现或 SOTA。

## v2.1：浏览器来源时间

浏览器取不到平台发言时间时，wirePrompt 发送 `timeSource=captured`；系统指令禁止据此推导事件日期、发言先后或修订关系。来源网页地址保留在本地证据，不加入 AI 请求。协议版本进入分析指纹；旧提问需用户重新选择并预览才再次发送。
