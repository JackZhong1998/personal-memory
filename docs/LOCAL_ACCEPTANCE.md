## 验收目标

## 已验证的边界

- 真实本地文件 → 解析 → SQLite → 应用界面：两种来源均已出现真实对话及输入。
- 应用中点击“立即同步”：显示“同步结束 · 新增 0 条”。
- 暂停：本地来源均显示已暂停，同步按钮禁用；恢复后重新开启采集。
- 重启：仍显示 2 个应用、24 段对话、121 条用户提问。
- 独立文件监听测试：在临时豆包工作目录追加一条用户需求，真实监听器自动入库，重复同步不再新增。
- 71 项 Node 测试全部通过，涵盖解析、SQLite、历史扫描、来源隔离、去重、重启持久化、取消、导入和监听。
- 原生辅助组件在本机 ARM64 编译成功；应用通过 `codesign --verify --deep --strict`。
- 官网静态检查和 Git diff 空白检查通过。

## 本次修复

1. 新增豆包工作本地 Agent 需求采集、自动监听、设置开关与独立来源分类。
2. Codex 改为流式读取 JSONL，真实读取约 119.6 MB 的历史文件，不再因整个文件超过 100 MB 而跳过。
3. 排除系统上下文、审批记录、应用内部通知及心跳；提取文件包装中的真实请求和交互问答中的用户回答。
4. 升级时将旧的系统包装记录标为不展示，原始记录仍保留在 SQLite；修正对话标题，保留真实提问 ID。
5. 分析禁用时不再在启动快照中检查钥匙串；增加无用户正文的启动阶段诊断。
6. Swift 模块缓存写入构建目录，解决受限环境中的原生组件编译失败。

## 功能范围

豆包工作目前覆盖其已落盘到本机 `.sessions` 的主 Agent 用户需求；不等于完整云端账号历史。仅采集用户输入，排除助手回答、工具结果和子任务。展示按来源和对话组织，当前未开启自动主题分类或新记忆分析。
