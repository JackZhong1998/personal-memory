# 豆包工作 PC 本地采集

v0.7.2 已针对 macOS 豆包工作 2.33.5 的真实本地文件完成接入。

## 数据来源与范围

默认目录：

```text
~/Library/Application Support/DoubaoWork/Default/.doubaowork/agent_mode/workspace/.sessions/
  <session-id>/agents/m_<agent-id>/system/assignment.md
```

每个带时间戳的“需求”段落对应一条用户输入。同一 session 聚合成一段对话，来源独立标为“豆包工作”，与普通豆包区分。默认开启历史扫描和后续文件变化监听；连接设置中可以关闭、暂停或立即同步。

仅同步主 Agent 的用户需求，排除 `s_`、`o_` 子 Agent，以及 `<system-reminder>` 等内部通知。执行日志中的助手、工具输出不入库。原始平台文件始终只读，且不读取登录凭据。

## 时间、更新与去重

- 保留需求段落的原始时间；原始高精度时间参与稳定 ID 计算。
- 重复同步和重启不会重复新增。相同时间段落的文本修改更新已有记录。
- 同一时间出现多条用户输入时，以出现顺序区分。
- 一个失败文件不会阻塞其余会话。错误显示在应用中。
- 数据目录或会话文件中的符号链接不会被遍历。

## 能力边界

这条链路覆盖实际保存到上述目录的本地 Agent 会话。普通云端聊天、未缓存消息、仅在其他电脑存在的历史，以及平台已经丢弃的早期需求，不在本地扫描范围。当前未把 IndexedDB 中的会话目录缓存冒充完整消息历史。

应用只采集用户输入；不采集助手回答、附件正文、子 Agent 指令或生成的文件。按应用与对话分组展示，当前不做自动主题分类。

## 验证

新增测试覆盖主 Agent 筛选、内部通知排除、原始时间、重复用户输入、编辑更新、追加历史、重启去重、取消与符号链接拒绝。真实本机扫描结果与应用内验收记录见 `LOCAL_ACCEPTANCE.md`。
